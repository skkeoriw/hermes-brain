# Telegram Report Template (Brain Sync)

Template sections:
- A. 核心摘要
  - 2-3 bullet points with concrete changes
- B. 详细变更
  - File changes count, insertions, deletions
  - 新增文件清单 (if any)
  - 修改文件清单 (if any)
- C. 快速导航
  - Compare: https://github.com/OWNER/REPO/compare/PREV...CUR
  - Commit: https://github.com/OWNER/REPO/commit/CUR

Usage:
- Populate from git metadata: HEAD, HEAD~1, diff stats, and origin URL.
- Replace OWNER/REPO, PREV, CUR with actual values.
