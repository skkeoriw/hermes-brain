## Pitfalls

### 0. git ls-files 俄文/中文文件名导致 FileNotFoundError
当 wiki/sources 目录下的文件名包含非 ASCII 字符（如中文）时，`git ls-files` 默认会为这些文件添加引号和转义，导致 Python `Path / filename` 拼接出错（FileNotFoundError）。修复方法：`git ls-files` 加 `-z` 参数（NUL 分隔），然后用 `\0` split 代替 `splitlines()`。

### 1. uncertain 频繁出现
说明 wiki 文件系统状态不一致（如手动操作遗留文件）。用 `git -C $WIKI_PATH status` 查看脏文件并清理。

### 2. TG 未发送（tg_sent: false）
检查 `~/.agent-brain-plugins.env` 里 `YOUTUBE_WIKI_TG_TOKEN` 是否有效：
`curl -s "https://api.telegram.org/bot${YOUTUBE_WIKI_TG_TOKEN}/getMe"`

### 3. brain push 失败
检查 `~/agent-brain-plugins` 的 git remote 和 token：
`git -C ~/agent-brain-plugins remote -v`
